## 本章目标

## 核心内容

### LLM 的发展脉络

LLM 不是凭空出现的，它有一条清晰的技术演进线：

1. **RNN/LSTM 时代**：用循环结构处理序列，但难以捕捉长距离依赖，且无法并行。
2. **Transformer（2017，"Attention Is All You Need"）**：抛弃循环，纯用注意力机制。这是现代 LLM 的基石——可并行、能捕捉长程依赖。
3. **GPT 系列（2018+）**：基于 Transformer 的**解码器（decoder-only）**架构，用"预测下一个 token"这一简单目标在海量文本上预训练，模型规模从 GPT-1（1.17 亿参数）一路扩大到 GPT-3（1750 亿）。
4. **指令微调 + RLHF（2022+）**：ChatGPT 让人们意识到，光有预训练不够——还要用"指令-回答"对做微调（SFT），再用人类反馈强化学习（RLHF）对齐，才能得到听话、有用的助手。

### 两阶段训练范式（核心认知）

现代 LLM 几乎都遵循这个范式，本书也围绕它展开：

```
阶段一：预训练（Pretraining）        阶段二：微调（Fine-tuning）
┌──────────────────────┐          ┌──────────────────────────┐
│ 海量无标注文本        │          │ 有标注的下游数据          │
│ 目标：预测下一个 token │   ──→   │ 分类微调 / 指令微调        │
│ 产出：基座模型(base)  │          │ 产出：能干活的模型         │
│ 本书：ch02-ch05       │          │ 本书：ch06 分类 / ch07 指令│
└──────────────────────┘          └──────────────────────────┘
```

- **预训练**烧钱、烧算力，但只做一次，产出通用的"语言理解能力"。
- **微调**便宜、快，用少量标注数据让基座模型适配具体任务（分类、对话等）。

### 自回归（Autoregressive）生成

GPT 是**自回归**模型：根据已有的前 N 个 token，预测第 N+1 个 token；再把预测出的 token 加进上下文，继续预测下一个，如此循环生成文本。这个机制决定了后面所有章节的设计——从滑动窗口数据采样（ch02）到注意力掩码（ch03）。

### 关键概念（中英对照）

| 中文 | English | 说明 |
|------|---------|------|
| 大语言模型 | LLM (Large Language Model) | 基于海量文本训练的大型神经网络语言模型 |
| Transformer | Transformer | 2017 年提出的注意力架构，现代 LLM 的基石 |
| 解码器架构 | Decoder-only | GPT 系列采用的结构，只用 Transformer 的解码器部分 |
| 自回归 | Autoregressive | 逐 token 预测下一个 token 的生成方式 |
| 预训练 | Pretraining | 在大规模无标注文本上做下一词预测训练 |
| 微调 | Fine-tuning | 在预训练模型上用有标注数据适配下游任务 |
| 指令微调 | Instruction fine-tuning (SFT) | 用"指令-回答"对让模型学会遵循指令 |
| 人类反馈强化学习 | RLHF | 用人类偏好做强化学习来对齐模型 |
| 词表 | Vocabulary | 模型能识别的所有 token 集合 |
| 词元 | Token | 文本被切分后的最小单位 |
| 上下文长度 | Context size | 模型一次能处理的最大 token 数 |
| 基座模型 | Base model | 仅预训练、未微调的模型 |
